04 / CODE LAB

Validation query patterns

Illustrative SQL examples for interview discussion. Confirm table and column names against the current catalog before execution.

SQL / Row-count validation
SELECT 'dim_customer_360' AS dataset, COUNT(*) AS row_count
FROM dev_customer360.gold.dim_customer_360
UNION ALL
SELECT 'fact_orders', COUNT(*)
FROM dev_customer360.gold.fact_orders
UNION ALL
SELECT 'fact_order_items', COUNT(*)
FROM dev_customer360.gold.fact_order_items;
Compare observed counts against your validation record.
SQL / Unique-key check
SELECT customer_unique_id, COUNT(*) AS n
FROM dev_customer360.gold.dim_customer_360
GROUP BY customer_unique_id
HAVING customer_unique_id IS NULL
    OR COUNT(*) > 1;
Expected result for a unique-key dimension: zero rows.
